# GOBLIN

**Консольная RPG на C · Итальянский интерфейс · Прототип**

> Один герой. Один гоблин. Золото, улучшения и бой, в котором нужно пережить ответные атаки врага.
>
> **Статус проекта:** ранний прототип (не готовый релиз). Реализованы базовые механики, но часть из них требует исправления и балансировки. Будущие возможности перечислены в [ROADMAP.md](ROADMAP.md), а не представлены как уже существующие.

## Об игре

**Goblin** — небольшая текстовая ролевая игра, написанная на языке **C**. Игрок управляет героем, пытается победить гоблина и распределяет ограниченные ресурсы между атакой, работой, отдыхом и покупками.

В текущей версии задача одна: победить единственного гоблина, сохранив здоровье персонажа. Победа или гибель героя завершают игровой сеанс. Подземелий, нескольких противников, сохранений или графического интерфейса **пока нет**.

Игра выводит сообщения и меню **на итальянском языке**.

## Что уже работает

| Система | Текущая реализация |
|---|---|
| Персонаж | Имя, здоровье, броня, базовый и дополнительный урон, уровень, золото |
| Противник | Гоблин со здоровьем, уроном и уровнем |
| Бой | Атака игрока и ответная атака гоблина, если тот выжил |
| Экономика | Работа приносит золото с задержкой между действиями |
| Восстановление | Сон и еда восстанавливают здоровье |
| Магазин | Лечение, броня, урон, универсальное улучшение, зелье усиления |
| Прокачка | Повышение характеристик и награда золотом при увеличении уровня |
| События по времени | Усиление гоблина и отдельные атаки по таймеру |
| Промокоды | Ввод бонусных кодов |

**Стартовые параметры текущей версии:**

| Параметр | Герой | Гоблин |
|---|---:|---:|
| Здоровье | 60 | 150 |
| Броня | 5 | — |
| Базовый урон | 13.2 | 9.0 |
| Уровень | 1 | 1 |
| Золото | 100 | — |

Текущие интервалы в коде: **30 секунд** между работами, **30 секунд** между отдыхами, **30 секунд** до очередного усиления гоблина и **75 секунд** до отдельной атаки гоблина. Важно: эти события проверяются между действиями меню, а не независимым фоновым потоком.

### Управление

В главном меню используется числовой выбор:

| Команда | Действие |
|---:|---|
| 0 | Посмотреть характеристики |
| 1 | Атаковать |
| 2 | Работать |
| 3 | Отдыхать (сон или еда) |
| 4 | Открыть магазин |
| 5 | Ввести промокод |

## Сборка и запуск

В репозитории сейчас только один файл исходного кода: **goblin.it.c**. Для сборки нужен совместимый компилятор C и среда с доступным заголовком **unistd.h** (например, Linux/macOS).

**Следующие команды предназначены для автора проекта и лиц, получивших разрешение правообладателя на использование кода.** Описание сборки само по себе не предоставляет лицензии.

    cc -std=c11 -Wall -Wextra -Wpedantic goblin.it.c -o goblin
    ./goblin

При запуске программа предложит указать имя персонажа и откроет игровое меню. Сохранения между запусками нет.

## Известные ограничения

Прототип ещё не прошёл полноценный цикл тестирования. По анализу исходного кода обнаружены следующие проблемы:

- Ввод имени и промокода через scanf без ограничения длины строки — потенциальное переполнение буфера.
- Повышение уровня во время работы использует счётчик отдыха; в некоторых состояниях уровень повышается при каждой работе.
- Зелье, обозначенное как временное на пять ходов, фактически увеличивает урон без истечения эффекта.
- Промокоды можно активировать повторно.
- Здоровье восстанавливается без ограничения максимальным значением.
- Полноценная механика критического удара ещё не реализована.
- При большой броне сообщение о полученном уроне может содержать отрицательное значение.
- Ввод нечислового текста вместо команд обрабатывается ненадёжно.
- Нет сохранения, разнообразия противников, тестов и автоматизированной сборки.

Эти пункты — **выявленные задачи для исправления**, а не уже внесённые изменения. Детальный перечень и критерии готовности находятся в [ROADMAP.md](ROADMAP.md).

### Идея развития

В перспективе Goblin может стать компактной **пошаговой RPG с элементами roguelite**: подготовка в деревне → исследование подземелья → бои и события → сражение с боссом. Это **концепция**, а не описание текущей версии.

Первый шаг — закончить и протестировать именно консольную версию на C. Графика и дополнительные платформы не входят в ближайшее обязательное обновление.

## English overview

**Goblin** is an early-stage, Italian-language **console RPG prototype written in C**. The player fights a single goblin, earns gold, rests, buys stat improvements, and tries to survive. The current game ends after either victory or defeat.

**Implemented:** a console menu, basic combat, player/enemy stats, a shop, timed events, rest, work, and promo-code input.

**Not implemented yet:** a multi-encounter campaign, proper turn-based tactical combat, inventory, boss encounters, save/load, automated tests, 2D graphics, or browser support. The prototype also has known correctness and input-handling issues.
